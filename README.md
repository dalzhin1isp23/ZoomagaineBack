# ZooMagazine Backend

Backend-часть интернет-магазина товаров для животных **ZooMagazine**.

Проект отвечает за работу с данными, авторизацию пользователей, каталог товаров и бизнес-логику интернет-магазина.

Frontend проекта находится в отдельном репозитории.

## Возможности

* регистрация и авторизация пользователей;
* работа с пользователями;
* хранение и обработка данных товаров;
* фильтрация товаров по категориям и типам;
* расчёт скидок;
* загрузка и хранение файлов;
* работа с базой данных;
* API для взаимодействия с клиентской частью приложения.

## Структура проекта

```text
src/
├── models/        # Модели данных
├── ...            # Контроллеры, маршруты и бизнес-логика

uploads/           # Загруженные файлы

.postman/          # Коллекции и настройки для тестирования API

migrate-mongo-config.js
package.json
```

## Технологии

* Node.js
* JavaScript
* MongoDB
* Mongoose
* Express
* Mongo Migrate

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/dalzhin1isp23/ZoomagaineBack.git
```

Перейдите в папку проекта:

```bash
cd ZoomagaineBack
```

Установите зависимости:

```bash
npm install
```

## Настройка базы данных

Для работы проекта необходимо настроить подключение к MongoDB.

Параметры подключения должны быть указаны в конфигурации проекта или переменных окружения.

При необходимости используйте миграции:

```bash
npm run migrate
```

Доступные команды могут зависеть от конфигурации `package.json`.

## Запуск

Для запуска проекта используйте команду, указанную в `package.json`:

```bash
npm start
```

или режим разработки:

```bash
npm run dev
```

## Тестирование API

В репозитории присутствуют материалы для работы с Postman. Их можно использовать для проверки API-эндпоинтов.
